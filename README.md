# Lyra Compliance AI

AI Compliance Copilot for Swedish SMEs.

## Overview

Lyra Compliance Gen AI helps Swedish startups and SMEs understand regulatory obligations, VAT requirements, employment regulations, corporate governance, and shareholder-related compliance through an AI-powered conversational interface.

## Features

- Swedish VAT guidance
- Corporate compliance support
- Employment regulation guidance
- Tax obligation assistance
- Shareholder agreement recommendations
- Official source references
- Actionable compliance recommendations

## Tech Stack

- Google ADK
- NVIDIA Nemotron
- LiteLLM
- Python

pip install -r requirements.txt
